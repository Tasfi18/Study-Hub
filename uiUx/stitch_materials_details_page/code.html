Description

These comprehensive notes cover the fourth week of the CS101 curriculum, focusing specifically on non-linear data structures. The document includes detailed explanations of Binary Search Trees (BST), AVL Trees, and Heaps.

Key topics included:

  • Tree traversal algorithms (In-order, Pre-order, Post-order)
  • Balancing mechanisms for AVL trees
  • Binary Heap implementation (Min-heap and Max-heap)
  • Big-O notation for tree operations

Perfect for exam preparation. Includes practice problems at the end of the PDF.
